# Agent Instructions

Adhere to the following workflow for all future sessions:

1.  **Always Sync to Repo**: Commit and push changes frequently.
2.  **Linting & Formatting**: Always ensure the project is linted with ESLint and formatted with Prettier before completing a task.
3.  **Dependency Updates**: Check for and install the latest package updates regularly (`npm update`).
4.  **Accessibility**: Ensure all new UI features pass WCAG accessibility checks.

Reference these instructions at the start of every session.
